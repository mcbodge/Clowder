Refactor installation/update, all planning-capable prompts, installation skill, and README for copilot|antigravity|all; optional MudBlazor; safe MCP registration; immediate interactive clarification.

- Omitting MudBlazor removes only known Clowder MudBlazor extras in the selected targets. No persisted selection. Unrelated user files and existing MCP entries remain.

No package-version detection or default documentation version.

Plain Copilot copy-only installs keep existing prerequisites; Node alone is required for Antigravity or MCP operations. - Antigravity project installs in git repositories idempotently exclude docs/plans/.clowder-notes/ through the actual git info/exclude path; planner/auditor preambles explicitly prohibit writes outside docs/plans/**.
